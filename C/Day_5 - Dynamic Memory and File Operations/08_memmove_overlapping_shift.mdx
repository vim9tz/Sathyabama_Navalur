# Move Overlapping Memory with memmove

## Problem Description

Create the array `{10, 20, 30, 40, 50, 60}` and use `memmove` to move its first
three elements two positions to the right. The source and destination overlap.

## Sample Input

No input required.

## Sample Output

```text
Original Array:
10 20 30 40 50 60

Array after shifting 3 elements right by 2 positions:
10 20 10 20 30 60
```
