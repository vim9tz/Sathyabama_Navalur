# Clear a Dynamic Buffer with memset

## Problem Description

Allocate memory for five integers with `malloc`. Use `memset` to set every byte
in the allocation to zero and display the resulting elements.

## Sample Input

No input required.

## Sample Output

```text
arr[0] = 0
arr[1] = 0
arr[2] = 0
arr[3] = 0
arr[4] = 0
```
