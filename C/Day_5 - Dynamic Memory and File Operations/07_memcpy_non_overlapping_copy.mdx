# Copy Non-Overlapping Memory with memcpy

## Problem Description

Allocate separate source and destination arrays. Fill the source with five
multiples of ten and copy its complete memory block into the destination using
`memcpy`.

## Sample Input

No input required.

## Sample Output

```text
dest[0] = 10
dest[1] = 20
dest[2] = 30
dest[3] = 40
dest[4] = 50
```
