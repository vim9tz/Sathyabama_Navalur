# Read a Text File Line by Line

## Problem Description

Open `student_report.txt` in read mode and display every line using `fgets` and
`fputs`. Run lesson 09 first to create the input file.

## Sample Input

Existing `student_report.txt`:

```text
Student: Anu
C Programming Mark: 92
```

## Sample Output

```text
--- Student Report ---
Student: Anu
C Programming Mark: 92
```
