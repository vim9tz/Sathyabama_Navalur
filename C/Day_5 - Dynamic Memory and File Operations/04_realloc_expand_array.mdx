# Expand a Dynamic Array with realloc

## Problem Description

Allocate an array for three integers, store `10`, `20`, and `30`, then safely
expand it to six integers with a temporary pointer. Add three more values and
display the complete array.

## Sample Input

No input required.

## Sample Output

```text
arr[0] = 10
arr[1] = 20
arr[2] = 30
arr[3] = 40
arr[4] = 50
arr[5] = 60
```
