# Zero-Initialized Allocation with calloc

## Problem Description

Use `calloc` to allocate five integers. Display every element to demonstrate that
the allocated bytes begin at zero, then release the memory.

## Sample Input

No input required.

## Sample Output

```text
arr[0] = 0
arr[1] = 0
arr[2] = 0
arr[3] = 0
arr[4] = 0
```
