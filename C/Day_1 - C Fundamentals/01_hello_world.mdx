# Hello World in C

## Problem Description

Write your first C program. Include the standard input/output header, define the
`main` function, print a welcome message, and return `0`.

## Requirements

- Use `#include <stdio.h>`.
- Use `int main(void)`.
- Print the message exactly as shown.

## Sample Input

No input required.

## Sample Output

```text
Hello, C Programming!
```
