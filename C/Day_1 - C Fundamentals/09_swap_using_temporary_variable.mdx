# Swap Coordinates Using Two Methods

## Problem Description

Read two coordinates. Swap them first with a temporary variable, restore the original values, and then swap them using arithmetic operations.

## Sample Input

```text
10
20
```

## Sample Output

```text
Coord A = 20 and Coord B = 10 is Swapped using temp
Coord A = 20 and Coord B = 10 is Swapped using arithmetic
```
