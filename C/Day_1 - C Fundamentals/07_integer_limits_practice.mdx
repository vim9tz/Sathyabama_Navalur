# Debugging Integer Input

## Problem Description

Review the program that displays integer limits and accepts an age and student ID. Identify and correct the invalid `scanf` argument so the program safely stores both inputs.

## Sample Input

```text
19
10025
```

## Expected Output After Correction

```text
Signed INT range: -2147483648 to 2147483647
Unsigned INT max: 4294967295
Age : 19 years old
Student ID: 10025
```

> The exact limits can vary by C implementation.
