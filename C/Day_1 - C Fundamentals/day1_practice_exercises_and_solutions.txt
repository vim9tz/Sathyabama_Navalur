PROBLEM 1: Coordinate Swap Using Temporary Variable
--------------------------------------------------------------------------------
[Problem Description]
Swaps two user-provided coordinates using a temporary holding variable 
(Profile 1) and displays the values before and after swapping.

Sample Input:
10
20

Sample Output:
Profiles before swap is 10 and 20.
Profiles after swap is 20 and 10.

[Solution Code]
#include <stdio.h>

int main() {
    int p1, p2, temp;
    if (scanf("%d %d", &p1, &p2) != 2) return 1;

    printf("Profiles before swap is %d and %d.\n", p1, p2);

    temp = p1;
    p1 = p2;
    p2 = temp;

    printf("Profiles after swap is %d and %d.\n", p1, p2);
    return 0;
}

PROBLEM 2: Coordinate Swap Without Temporary Variable
--------------------------------------------------------------------------------
[Problem Description]
Swaps two user-provided coordinates using pure math without a third variable 
(Profile 2) and displays the values before and after swapping.

Sample Input:
10
20

Sample Output:
Profiles before swap is 10 and 20.
Profiles after swap is 20 and 10.

PROBLEM 3: Mixed-Type Integer and Float Operations
--------------------------------------------------------------------------------
[Problem Description]
Reads two integers on Line 1 and two floats on Line 2. Outputs the integer sum 
and difference, followed by the float sum and difference rounded to 1 decimal place.

Sample Input:
10 4
4.5 2.1

Sample Output:
14 6
6.6 2.4

[Solution Code]
#include <stdio.h>

int main() {
    int int1, int2;
    float float1, float2;

    if (scanf("%d %d", &int1, &int2) != 2) return 1;
    if (scanf("%f %f", &float1, &float2) != 2) return 1;

    printf("%d %d\n", int1 + int2, int1 - int2);
    printf("%.1f %.1f\n", float1 + float2, float1 - float2);

    return 0;
}

PROBLEM 4: Circle Area Calculation
--------------------------------------------------------------------------------
[Problem Description]
Calculates the area of a circle (Area = Pi * r^2) using an immutable single-precision 
floating-point constant for Pi (3.14159). Limits output to 2 decimal places.

Sample Input:
5.0

Sample Output:
78.54

[Solution Code]
#include <stdio.h>

int main() {
    const float PI = 3.14159f;
    float radius, area;

    if (scanf("%f", &radius) != 1) return 1;

    area = PI * radius * radius;
    printf("%.2f\n", area);

    return 0;
}

PROBLEM 8: Simple Interest Calculator
--------------------------------------------------------------------------------
[Problem Description]
Read principal, annual interest rate, and time in years. Calculate simple
interest using (principal * rate * time) / 100 and print the final amount.

Sample Input:
10000 7.5 2

Sample Output:
Simple Interest: 1500.00
Final Amount: 11500.00

PROBLEM 10: Seconds to Hours, Minutes, and Seconds
--------------------------------------------------------------------------------
[Problem Description]
Read a total number of seconds and convert it into hours, remaining minutes,
and remaining seconds using integer division and modulo.

Sample Input:
7384

Sample Output:
2 hour(s), 3 minute(s), 4 second(s)

[Solution Code]
#include <stdio.h>

int main(void) {
    int totalSeconds;
    if (scanf("%d", &totalSeconds) != 1) return 1;

    int hours = totalSeconds / 3600;
    int minutes = (totalSeconds % 3600) / 60;
    int seconds = totalSeconds % 60;

    printf("%d hour(s), %d minute(s), %d second(s)\n",
           hours, minutes, seconds);
    return 0;
}

PROBLEM 15: Employee Salary Breakdown

salary, then display the gross salary.

25000

HRA: 5000.00

PROBLEM 17: Left and Right Bit Shifts
--------------------------------------------------------------------------------
[Problem Description]
Read a non-negative integer and a shift count. Display the result after shifting
the number left and right by that count.

Sample Input:
20 2

Sample Output:
Left Shift: 80
Right Shift: 5

[Solution Code]
#include <stdio.h>

int main(void) {
    unsigned int number, positions;
    if (scanf("%u %u", &number, &positions) != 2) return 1;

    printf("Left Shift: %u\n", number << positions);
    printf("Right Shift: %u\n", number >> positions);
    return 0;
}
