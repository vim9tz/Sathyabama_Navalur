# Primitive Data Types and Memory Sizes

## Problem Description

Declare `char`, `int`, `float`, and `double` variables. Display the memory occupied by each variable and its stored value.

## Sample Input

No input required.

## Sample Output

```text
--- Memory Size of Data Types ---
char size:   1 byte(s)  | Value: A
int size:    4 byte(s)  | Value: 100
float size:  4 byte(s)  | Value: 5.750000
double size: 8 byte(s)  | Value: 99.999900
```

> Memory sizes may vary depending on the compiler and system.
