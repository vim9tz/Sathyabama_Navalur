# Integer Limits with User Input

## Problem Description

Display the system limits for signed and unsigned integers. Then read a student's age and unsigned ID and display both values.

## Sample Input

```text
20
4294967290
```

## Sample Output

```text
-- Hard limit --Signed INT range: -2147483648 to 2147483647
Unsigned INT max: 4294967295
Enter your age:Enter your student id: Age : 20 years old
Student ID: 4294967290
```

> The exact limits can vary by C implementation.
