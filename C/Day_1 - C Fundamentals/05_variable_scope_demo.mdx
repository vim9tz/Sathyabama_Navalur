# Variable Scope Demonstration

## Problem Description

Create global, function-level, and block-level variables. Print the accessible variables inside `main`, inside a nested block, and after leaving that block.

## Sample Input

No input required.

## Sample Output

```text
--- Main Block ---
Global Energy is: 100
Main Speed is: 50
--- Inside Block ---
Can see Global Energy 100
Can see Main Speed 50
Can see Local boost 25
--- Back in Main Block ---
Main speed is still: 50
```
