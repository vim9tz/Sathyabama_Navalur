# Sentinel-Controlled Temperature Tracker

## Problem Description

Read temperatures until `999` is entered. Use a `while` loop to report the number of readings, warmest value, coldest value, and average. Do not include the sentinel in the calculations.

## Sample Input

```text
-15 -28 -5 -32 -10 999
```

## Sample Output

```text
Enter temperatures (999 to stop): Readings: 5
Warmest: -5
Coldest: -32
Average: -18.00
```
