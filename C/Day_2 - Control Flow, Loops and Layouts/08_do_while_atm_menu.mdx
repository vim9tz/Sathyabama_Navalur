# Repeating ATM Menu Using do-while

## Problem Description

Display an ATM menu repeatedly using `do-while`. Use `switch` to process the
selected operation and stop only when the user chooses Exit.

## Sample Input

```text
1
4
```

## Sample Output

```text
--- ATM MENU ---
1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit
Enter your choice: Your balance is $500.

--- ATM MENU ---
1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit
Enter your choice: Thank you for using the ATM. Goodbye!
```
