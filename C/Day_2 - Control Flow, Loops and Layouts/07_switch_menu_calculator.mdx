# Menu Calculator Using switch

## Problem Description

Read an operation choice and two numbers. Use `switch` to perform addition, subtraction, multiplication, or division. Handle invalid choices and division by zero.

## Menu

1. Addition
2. Subtraction
3. Multiplication
4. Division

## Sample Input

```text
4
20 5
```

## Sample Output

```text
1.Add  2.Subtract  3.Multiply  4.Divide
Enter choice: Enter two numbers: Result: 4.00
```
