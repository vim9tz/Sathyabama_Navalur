# Grade Classifier Using if-else

## Problem Description

Read a mark from `0` to `100` and classify it as grade A, B, C, D, or F. Print an error when the value is outside the accepted range.

## Grade Ranges

- 90–100: A
- 75–89: B
- 60–74: C
- 50–59: D
- 0–49: F

## Sample Input

```text
78
```

## Sample Output

```text
Enter mark (0-100): Grade B
```
