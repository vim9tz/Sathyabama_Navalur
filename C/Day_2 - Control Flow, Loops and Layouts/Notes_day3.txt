RECURSION
1. Base Case
2. Recursive Call
3. Calling Phase / Winding Phase
4. Returning Phase / Unwinding Phase

SYNTAX EXAMPLE
int computeSum(int n) {
    
    if (n == 0) {         <-- [Base Case Condition]
        return 0;         <-- [Base Case Return / Unwinding Trigger]
    }
    
    else {
        return n + computeSum(n - 1);  <-- [Recursive Case Call]
    }                                  <-- [n - 1 is the Decrement]
}

THE CALL STACK VISUALIZATION (LIFO: LAST IN, FIRST OUT)
----------------------------------------------------------------------

During the calling phase, a stack of plates was built. During the 
returning phase, plates are taken off the top one by one:

   |                          |     
   |                          |     
   |--------------------------|     
   | Frame n = 3 (PAUSED)     | --> Pops off top next: Prints n = 3
   |--------------------------|     
   | Frame n = 2 (PAUSED)     | --> Then pops off next: Prints n = 2
   |--------------------------|     
   | Frame n = 1 (PAUSED)     | --> Finally pops off last: Prints n = 1
   |--------------------------|     
   | main()     (PAUSED)      | 
   \__________________________/



   sumOfDigits(1432) 
   = 2 + sumOfDigits(143)
   = 2 + (3 + sumOfDigits(14))
   = 2 + (3 + (4 + sumOfDigits(1)))
   = 2 + (3 + (4 + (1 + sumOfDigits(0))))   <-- Peak of Calling Phase
   = 2 + (3 + (4 + (1 + 0)))                <-- Base Case returns 0
   = 2 + (3 + (4 + 1))                      <-- Returning Phase begins
   = 2 + (3 + 5)
   = 2 + 8
   = 10                                     <-- Final Return to main()

puts(str)
  - Purpose: Writes a string of text character-by-character from a memory buffer onto the output screen.
  - Caution: It automatically appends an explicit newline character ('\n') to the end of the printed output, and it will crash with a Segmentation Fault if you pass a NULL pointer instead of a valid string address.
  - Example: `puts(my_string);`

fgets(buffer, size, stream)
  - Purpose: Reads an entire line of text from an input source, including spaces.
  - Caution: It preserves the trailing newline character ('\n') inside your buffer if there is space.
  - Example: `fgets(buffer, sizeof(buffer), stdin);`

sizeof(expression_or_type)
  - Purpose: Calculates the exact memory footprint size (in bytes) of a variable, array, or data type during compilation.
  - Caution: It returns the total allocated buffer memory size, not the active number of data items populated inside it.
  - Example: `int totalBytes = sizeof(my_array);`

strlen(str)
  - Purpose: Calculates the total number of visible characters.
  - Caution: It does NOT count the hidden `\0` character.
  - Example: `strlen("code")` returns `4`.

strcspn(string1, string2)
  - Purpose: Scans string1 from the beginning to calculate the length of the initial segment that contains absolutely zero characters from string2.
  - Caution: If none of the characters from string2 are found inside string1, it returns the total length of string1 (pointing directly to the hidden '\0' terminator position).
  - Example: `int index = strcspn(buffer, "\n");`

strcpy(destination, source)
  - Purpose: Copies the string from the source array into the destination.
  - Caution: Ensure the destination array is large enough to prevent a crash.
  - Example: `strcpy(buffer, "hello");

strcat(destination, source)
  - Purpose: Concatenates (joins) the source string onto the end of the destination string.
  - Example: If `str1` is "New ", `strcat(str1, "York")` mutates `str1` into "New York".

strcmp(str1, str2)
  - Purpose: Compares two strings character-by-character based on ASCII values.
  - Returns: `0` if identical, a negative number if `str1 < str2`, positive if `str1 > str2`.
  - Caution: It is case-sensitive ("Apple" does not equal "apple").

strcasecmp(string1, string2)
  - Purpose: Compares two strings character-by-character while completely ignoring upper and lower case differences.
  - Caution: It is a POSIX standard function (found inside <strings.h>). On Windows systems (MSVC), you must write it as `_stricmp` instead.
  - Example: `int status = strcasecmp(str1, str2);`


isalpha(c)  -> Returns true (non-zero) if the character is a letter (A-Z or a-z).
isdigit(c)  -> Returns true if the character is a numeric digit (0-9).
isalnum(c)  -> Returns true if the character is alphanumeric (either a letter or digit).
islower(c)  -> Returns true if the character is lowercase.
isupper(c)  -> Returns true if the character is uppercase.
tolower(c)  -> Converts a capital letter to lowercase. Returns unchanged if not a letter.
toupper(c)  -> Converts a lowercase letter to uppercase.

atoi(str)
  - Purpose: "ASCII to Integer". Converts a string of text digits into a real integer.
  - Example: `int val = atoi("1432");` transforms string numbers into numeric `1432`.

atof(str)
  - Purpose: "ASCII to Float". Converts a string into a decimal floating-point number.
  - Example: `float val = atof("3.14");`
abs(num)
  - Purpose: Returns the absolute value of an integer (removes negative signs).
  - Example: `abs(-5)` returns `5`
