# Class, Student, and Subject Averages

## Problem Description

Use three nested `for` loops to process classes, students, and subject marks.
Calculate and display the average mark for every student.

## Sample Input

```text
1
3
2
80 90 70
60 75 90
```

## Sample Output

```text
How many classes? How many subjects? How many students in Class 1? Enter 3 subject exam marks for student 1: -> Student 1 Average: 80.00
Enter 3 subject exam marks for student 2: -> Student 2 Average: 75.00
```
