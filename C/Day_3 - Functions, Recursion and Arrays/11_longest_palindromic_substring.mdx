# Longest Palindromic Substring in C

## Problem Description

Given a text string, filter out non-alphanumeric characters, convert all letters to lowercase, and find the longest palindromic substring using the expansion around center algorithm.

## Requirements

- Filter non-alphanumeric characters using `isalnum` and `tolower`.
- Implement `expandAroundCenter` function to find odd-length and even-length palindromes.
- Output the cleaned string, longest palindromic substring, start index, and length.

## Sample Input

```text
A man, a plan, a canal: Panama!
```

## Sample Output

```text
Cleaned String: amanaplanacanalpanama
Longest Palindromic Substring: "amanaplanacanalpanama"
Start Index: 0, Length: 21
```
