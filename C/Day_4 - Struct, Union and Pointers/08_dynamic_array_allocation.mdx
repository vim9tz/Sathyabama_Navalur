# Dynamic Memory Allocation (malloc, realloc, free) in C

## Problem Description

Demonstrate heap memory allocation using `malloc`, safety checking against `NULL`, expanding array size dynamically using `realloc`, and freeing heap memory using `free`.

## Requirements

- Allocate memory for 3 integers using `malloc`.
- Verify memory allocation success (`arr != NULL`).
- Populate initial array elements `{100, 200, 300}`.
- Expand allocation to 5 integers using `realloc`.
- Add new elements `{400, 500}` and print the expanded array.
- Free heap memory with `free(arr)` and set pointer to `NULL`.

## Sample Input

No input required.

## Sample Output

```text
Dynamically allocated array of size 3:
arr[0] = 100
arr[1] = 200
arr[2] = 300

Resized array dynamically to size 5:
arr[0] = 100
arr[1] = 200
arr[2] = 300
arr[3] = 400
arr[4] = 500

Memory successfully freed.
```
