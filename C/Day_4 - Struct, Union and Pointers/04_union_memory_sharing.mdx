# Union Memory Sharing in C

## Problem Description

Demonstrate `union` declaration, memory allocation behavior (sharing the same memory location across all members), member overwrite effects, and compare `sizeof(union)` with `sizeof(struct)`.

## Requirements

- Define a `union Data` and a `struct DataStruct` with identical member types (`int`, `float`, `char[20]`).
- Print sizes of both types to prove unions allocate memory equal to the largest member.
- Assign values sequentially and print after each assignment.
- Access previously written fields after writing to a new field to demonstrate corruption of non-active union members.

## Sample Input

No input required.

## Sample Output

```text
Size of union Data: 20 bytes
Size of struct DataStruct: 28 bytes

--- Setting Union Fields One by One ---
u.i = 10
u.f = 220.50
u.str = C Programming

--- Accessing Overwritten Union Members ---
u.i (corrupted value) = 1919899459
u.f (corrupted value) = 13823528776469440.00
u.str (valid value)   = C Programming
```
