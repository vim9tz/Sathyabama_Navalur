1. Root Element -> Everything on the page is normally contained inside it
<html>

             html
            /    \
         head    body

2. Parent -> An element containing another element is its parent.
<body>
    <h1>Welcome</h1>
    <div>
        <p>Hello</p>
    </div>
</body>

3. Child -> An element directly inside another element is its child.
<div>
    <h2>Student</h2>
    <p><em>Arun<em></p>
</div>
       div
      /   \
    h2     p

4. Siblings -> Elements that share the same parent are siblings.

<div>
    <h2>Student Details</h2>
    <p>Arun</p>
    <button>View</button>
</div>

           div
        /   |    \
      h2    p    button

5. Ancestor -> An ancestor is any element higher up in the tree.

<body>
    <div>

            <p>Hello</p>
        </section>
    </div>
</body>

HTML TREE STRUCTURE
=========================================

HTML elements are organized in a hierarchical tree structure.

ROOT
-----------------------------------------
<html>
Main/root HTML element.

PARENT
-----------------------------------------
Element directly containing another element.

CHILD
-----------------------------------------
Element directly inside another element.

SIBLING
-----------------------------------------
Elements having the same parent.

ANCESTOR
-----------------------------------------
Any element above another element.

DESCENDANT
-----------------------------------------
Any element contained somewhere below
another element.

EXAMPLE
-----------------------------------------
html
│
├── head
│   └── title
│
└── body
    │
    ├── h1
    │
    └── div
        │
        ├── h2
        ├── p
        └── button

For h2:
Parent      → div
Sibling     → p, button
Ancestors   → div, body, html

For div:
Children    → h2, p, button
Parent      → body
Ancestor    → body, html
