What is CSS?

CSS = Cascading Style Sheets

Explanation:

  1. HTML decides what is on the page.
  2. CSS decides how it looks and how it is arranged.
  3. JavaScript decides what it does.

Analogy:

  1. HTML = skeleton
  2. CSS = clothes + appearance
  3. JavaScript = behavior/actions

Syntax:

        selector {
            property: value;
        }

CSS Selectors:

  1. Universal Selector
  2. Element Selector
  3. Class Selector
  4. ID Selector
