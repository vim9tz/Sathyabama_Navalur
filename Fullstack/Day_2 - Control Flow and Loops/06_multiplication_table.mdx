# Multiplication Table Generator

## Problem Description
Write a Java program that reads a target multiplier integer and an iteration limit, then uses a `for` loop to display a clean, formatted multiplication table.

## Requirements
- Source file name: `06_multiplication_table.java`
- Class name: `_06_multiplication_table`
- Use formatted output printing (`System.out.printf`).

## Sample Input
```text
7
5
```

## Sample Output
```text
Enter number for table: 7
Enter limit (e.g., 10): 5
--- Multiplication Table of 7 ---
7 x  1 = 7
7 x  2 = 14
7 x  3 = 21
7 x  4 = 28
7 x  5 = 35
```
