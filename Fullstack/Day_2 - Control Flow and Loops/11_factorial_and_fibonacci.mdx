# Factorial & Fibonacci Series Generator

## Problem Description
Write a Java program that reads an integer `N`, computes its factorial ($N!$) using an accumulator product loop, and generates the first `N` terms of the Fibonacci sequence ($0, 1, 1, 2, 3, 5, \dots$).

## Requirements
- Source file name: `11_factorial_and_fibonacci.java`
- Class name: `_11_factorial_and_fibonacci`
- Use `long` data type to prevent overflow for large factorials.

## Sample Input
```text
7
```

## Sample Output
```text
Enter N for Factorial & Fibonacci: 7
Factorial of 7 (7!): 5040
Fibonacci Series (7 terms): 0, 1, 1, 2, 3, 5, 8
```
