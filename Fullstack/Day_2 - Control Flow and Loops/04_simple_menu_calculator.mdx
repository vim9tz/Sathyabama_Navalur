# Interactive Menu Calculator

## Problem Description
Create a menu-driven calculator that presents options for basic arithmetic operations (+, -, *, /) and evaluates the user's choice using a `switch` statement while safeguarding against division by zero.

## Requirements
- Source file name: `04_simple_menu_calculator.java`
- Class name: `_04_simple_menu_calculator`
- Check `num2 != 0` before executing division.

## Sample Input
```text
4
15
3
```

## Sample Output
```text
=== CALCULATOR MENU ===
1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
Enter choice (1-4): 4
Enter first number: 15
Enter second number: 3
Result: 5.0
```
