# Prime Number Checker

## Problem Description
Write an optimized prime number verification program that tests divisibility up to $\sqrt{N}$ (`i * i <= num`) and uses the `break` statement to exit early when a factor is discovered.

## Requirements
- Source file name: `10_prime_number_check.java`
- Class name: `_10_prime_number_check`
- Use loop optimization `i * i <= num`.

## Sample Input
```text
29
```

## Sample Output
```text
Enter an integer (> 1): 29
29 is a Prime number.
```
