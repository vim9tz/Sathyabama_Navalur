# Even Numbers Counter & Accumulator

## Problem Description
Write a Java program that accepts a numeric range (`start` to `end`) and uses counter (`count++`) and accumulator (`sum += i`) loop patterns to compute both the count and sum of all even numbers within that inclusive range.

## Requirements
- Source file name: `07_sum_and_count_even_numbers.java`
- Class name: `_07_sum_and_count_even_numbers`
- Use modulo operator `% 2 == 0` for even number detection.

## Sample Input
```text
1
10
```

## Sample Output
```text
Enter start of range: 1
Enter end of range: 10
--- Results ---
Total Even Numbers Found: 5
Sum of Even Numbers: 30
```
