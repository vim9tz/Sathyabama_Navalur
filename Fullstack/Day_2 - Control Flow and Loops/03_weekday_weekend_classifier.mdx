# Weekday / Weekend Classifier

## Problem Description
Write a Java program that reads a day number from 1 to 7 and uses traditional switch case grouping (`case 1: case 2: ...`) to classify the day as either a "Weekday" or a "Weekend".

## Requirements
- Source file name: `03_weekday_weekend_classifier.java`
- Class name: `_03_weekday_weekend_classifier`
- Handle invalid day numbers via `default`.

## Sample Input
```text
6
```

## Sample Output
```text
Enter day number (1 for Mon, 7 for Sun): 6
Type: Weekend (Rest Day)
```
