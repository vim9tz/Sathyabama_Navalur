# Number Sign Check

## Problem Description
Write a Java program that reads an integer from the user and checks whether the number is positive, negative, or zero using an `if-else if-else` decision ladder.

## Requirements
- Source file name: `01_number_sign_check.java`
- Class name: `_01_number_sign_check`
- Use `java.util.Scanner` for integer input.

## Sample Input
```text
-15
```

## Sample Output
```text
Enter an integer: -15
The number is Negative.
```
