# Nested Loop Star Pattern Generator

## Problem Description
Write a Java program that accepts a height parameter $H$ and uses nested `for` loops (outer for rows, inner for spaces/columns) to render both a Right-Angled Triangle pattern and an Isosceles Pyramid pattern.

## Requirements
- Source file name: `12_star_pattern_generator.java`
- Class name: `_12_star_pattern_generator`
- Outer loop controls row iteration; inner loops control space and asterisk counts.

## Sample Input
```text
4
```

## Sample Output
```text
Enter height of pattern (H): 4

--- Pattern 1: Right-Angled Triangle ---
* 
* * 
* * * 
* * * * 

--- Pattern 2: Isosceles Pyramid ---
   *
  ***
 *****
*******
```
