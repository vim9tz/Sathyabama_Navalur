# Month Days Calculator

## Problem Description
Write a program that takes a month number (1-12) and a year, and uses a Java switch expression with arrow syntax (`->`) to calculate the number of days in that month, taking leap years into consideration for February.

## Requirements
- Source file name: `02_month_days_calculator.java`
- Class name: `_02_month_days_calculator`
- Support leap year evaluation for month 2 (`(year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)`).

## Sample Input
```text
2
2024
```

## Sample Output
```text
Enter month number (1-12): 2
Enter year: 2024
Days in month 2 for year 2024: 29
```
