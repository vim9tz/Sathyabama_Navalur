# Sum of Digits Calculator

## Problem Description
Write a Java program that accepts an integer and uses a `while` loop with digit extraction arithmetic (`% 10` and `/ 10`) to calculate the sum of all digits in the number.

## Requirements
- Source file name: `08_sum_of_digits.java`
- Class name: `_08_sum_of_digits`
- Safely handle negative inputs using `Math.abs`.

## Sample Input
```text
4567
```

## Sample Output
```text
Enter an integer: 4567
Sum of digits for 4567 is: 22
```
