# Reverse Number & Palindrome Check

## Problem Description
Write a program that takes an integer `N`, constructs its reverse using digit arithmetic (`rev = rev * 10 + digit`), and checks whether the number is a palindrome (reads identical forward and backward).

## Requirements
- Source file name: `09_reverse_number_and_palindrome.java`
- Class name: `_09_reverse_number_and_palindrome`
- Preserve the original input value for comparison.

## Sample Input
```text
12321
```

## Sample Output
```text
Enter a positive integer: 12321
Original Number: 12321
Reversed Number: 12321
Result: 12321 is a Palindrome.
```
