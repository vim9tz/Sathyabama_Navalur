# Restaurant Ordering System

## Problem Description
Design an interactive ordering system using nested `switch` statements. The user selects a food category (Starters, Main Course, Desserts), then chooses an item from the sub-menu, specifies the quantity, and receives a calculated total bill.

## Requirements
- Source file name: `05_restaurant_order_system.java`
- Class name: `_05_restaurant_order_system`
- Support sub-menu selections via nested `switch`.

## Sample Input
```text
2
1
2
```

## Sample Output
```text
=== MAIN MENU ===
1. Starters
2. Main Course
3. Desserts
Select Category: 2
--- Main Course ---
1. Veg Biryani (₹250)
2. Butter Naan with Paneer (₹300)
Choose item: 1
Enter quantity: 2

=== ORDER SUMMARY ===
Item: Veg Biryani
Quantity: 2
Total Amount: ₹500
```
