JAVA SWITCH - QUICK NOTES
=========================

+----------------------------------------+---------------------------------------------+
| TOPIC                                  | RULE / EXPLANATION                          |
+----------------------------------------+---------------------------------------------+
| switch                                 | Used to match fixed/exact values            |
| case                                   | Defines a possible matching value           |
| break                                  | Exits the switch                            |
| default                                | Runs when no case matches                   |
| Fall-through                           | Happens when break is missing               |
| default mandatory?                     | No                                          |
| break mandatory?                       | No, but usually needed in traditional switch|
| Multiple cases                         | Yes, cases can share the same code          |
| Duplicate cases                        | Not allowed                                 |
| int                                    | Supported                                   |
| byte                                   | Supported                                   |
| short                                  | Supported                                   |
| char                                   | Supported                                   |
| String                                 | Supported                                   |
| enum                                   | Supported                                   |
| long                                   | Not supported in traditional switch         |
| float                                  | Not supported                               |
| double                                 | Not supported                               |
| boolean                                | Not supported                               |
| Runtime variable as case               | Not allowed                                 |
| Constant as case                       | Allowed                                     |
| if inside case                         | Allowed                                     |
| Nested switch                          | Allowed                                     |
| Multiple fixed values                  | Allowed                                     |
| Range directly in case                 | Not allowed in traditional switch           |
| case mark >= 50                        | Invalid                                     |
| case 50                                | Valid                                       |
| String matching                        | Case-sensitive                              |
| Modern switch ->                       | Supported                                   |
| break with ->                          | Not required                                |
| Switch expression                      | Can return/produce a value                  |
| yield                                  | Produces value from switch expression block |
+----------------------------------------+---------------------------------------------+


IF-ELSE VS SWITCH
=================

+----------------------------------------+------------------+
| REQUIREMENT                            | USE              |
+----------------------------------------+------------------+
| age >= 18                              | if               |
| mark >= 50                             | if               |
| mark >= 80 && attendance >= 75         | if               |
| salary > 50000                         | if               |
| value < 100                            | if               |
| Checking ranges                        | if / else-if     |
| Complex conditions                     | if / else-if     |
| && conditions                          | if               |
| || conditions                          | if               |
| Day 1, 2, 3, 4...                      | switch           |
| Month 1, 2, 3...                       | switch           |
| Menu 1, 2, 3...                        | switch           |
| Operator +, -, *, /                    | switch           |
| Grade A, B, C, D                       | switch           |
| Role admin/student/trainer             | switch           |
| Multiple fixed choices                 | switch           |
+----------------------------------------+------------------+


IMPORTANT SWITCH RULES
======================

+----------------------------------------+---------------------------------------------+
| RULE                                   | EXAMPLE                                     |
+----------------------------------------+---------------------------------------------+
| Exact value                            | case 50:                                    |
| Range                                  | case mark >= 50:  INVALID                   |
| Condition                              | if (mark >= 50) INVALID                            |
| Multiple traditional cases             | case 1: case 2: case 3:                     |
| Multiple modern cases                  | case 1, 2, 3 ->                             |
| Character                              | case 'A':                                   |
| String                                 | case "admin":                               |
| Integer                                | case 1:                                     |
| Constant                               | final int X = 1; case X:                    |
| Duplicate value                        | case 1: case 1:  INVALID                    |
+----------------------------------------+---------------------------------------------+


BREAK AND FALL-THROUGH
======================

+----------------------+-----------------------------------------------+
| WITH BREAK           | WITHOUT BREAK                                 |
+----------------------+-----------------------------------------------+
| Executes matched case| Executes matched case                         |
| break stops execution| Continues to following cases                  |
| Exits switch         | Stops at break or end of switch               |
| No fall-through      | Called fall-through                           |
+----------------------+-----------------------------------------------+


TRADITIONAL VS MODERN SWITCH
============================

+--------------------------+-------------------------+-------------------------+
| FEATURE                  | TRADITIONAL             | MODERN                  |
+--------------------------+-------------------------+-------------------------+
| Case syntax              | case 1:                 | case 1 ->               |
| break                    | Usually required        | Not required            |
| Fall-through             | Possible                | No traditional          |
|                          |                         | fall-through            |
| Multiple values          | case 1: case 2:         | case 1, 2 ->            |
| Can produce value        | Not directly            | Yes                     |
| yield                    | No                      | Yes, in block expression|
+--------------------------+-------------------------+-------------------------+

RANGES
======

+------------------------------------+----------------------------+
| CODE                               | VALID / INVALID            |
+------------------------------------+----------------------------+
| case 50:                           | VALID                      |
| case 100:                          | VALID                      |
| case mark >= 50:                   | INVALID                    |
| case mark > 50 && mark <= 100:     | INVALID in basic switch    |
| if (mark >= 50)                    | VALID                      |
| if (mark >= 50 && mark <= 100)     | VALID                      |
+------------------------------------+----------------------------+

RULE:

IF-ELSE  = CONDITIONS / COMPARISONS / RANGES
SWITCH   = FIXED CHOICES / EXACT VALUES


EASY WAY TO REMEMBER
====================

IF-ELSE:
"Is this CONDITION true?"

Example:
mark >= 50
age >= 18
salary > 50000
age >= 18 && citizen


SWITCH:
"Which VALUE does this match?"

Example:
1 -> Monday
2 -> Tuesday

'A' -> Excellent
'B' -> Good

"admin"   -> Full Access
"student" -> Student Access
