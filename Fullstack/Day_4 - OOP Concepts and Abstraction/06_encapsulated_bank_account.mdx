# Encapsulated Bank Account

## Problem Description
Design a `SecureBankAccount` class leveraging Encapsulation. Mark fields `private`, provide public getter methods, and enforce validation constraints inside setters and transaction operations to safeguard account state against unauthorized external corruption.

## Requirements
- Source file name: `06_encapsulated_bank_account.java`
- Class name: `_06_encapsulated_bank_account`
- Reject negative initial balances and invalid transaction amounts.
