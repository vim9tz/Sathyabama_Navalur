# Multiple Interface Implementation

## Problem Description
Demonstrate how Java achieves multiple inheritance of behavior without class ambiguity by implementing multiple distinct interface contracts (`Printable`, `Scannable`, `Faxable`) in a single concrete class (`MultiFunctionPrinter`).

## Requirements
- Source file name: `11_multiple_interface_implementation.java`
- Class name: `_11_multiple_interface_implementation`
- Implement comma-separated interfaces: `class ClassName implements InterfaceA, InterfaceB, InterfaceC`.
