# Fleet Management Capstone (OOP Principles)

## Problem Description
Design a Fleet Management Capstone combining Encapsulation (`private` state with getters/setters), Abstraction (abstract class `FleetVehicle`), Polymorphism (`performMaintenanceCheck()`), and Interfaces (`GPSConnectable`).

## Requirements
- Source file name: `12_vehicle_management_capstone.java`
- Class name: `_12_vehicle_management_capstone`
- Seamlessly integrate all 4 pillars of Object-Oriented Programming into a single application.
