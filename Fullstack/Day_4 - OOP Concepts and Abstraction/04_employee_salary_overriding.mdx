# Salary Calculation (Method Overriding)

## Problem Description
Design a parent class `GenericEmployee` with method `calculateSalary()`. Subclasses `FullTimeEmployee` (monthly salary) and `PartTimeEmployee` (hours $\times$ hourly rate) override `calculateSalary()` to provide tailored compensation logic.

## Requirements
- Source file name: `04_employee_salary_overriding.java`
- Class name: `_04_employee_salary_overriding`
- Enforce the `@Override` annotation on overridden methods.

## Sample Output
```text
--- Salary Calculation (Method Overriding) ---
ID: 101 | Name: Suresh Kumar | Computed Salary: ₹45000.0
ID: 102 | Name: Meera Sen | Computed Salary: ₹28000.0
```
