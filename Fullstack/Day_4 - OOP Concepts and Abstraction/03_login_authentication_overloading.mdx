# Login Method Overloading

## Problem Description
Construct an `AuthenticationService` class featuring overloaded `login` methods accepting `(String email, String password)` versus `(long mobileNumber, String password)`.

## Requirements
- Source file name: `03_login_authentication_overloading.java`
- Class name: `_03_login_authentication_overloading`
- Differentiate method calls by parameter types (`String` vs `long`).

## Sample Output
```text
--- Multi-Channel Login ---
Authenticating via Email [admin@company.com]...
Status: Email authentication successful.

Authenticating via Mobile Number [+91-9876543210]...
Status: Mobile authentication successful.
```
