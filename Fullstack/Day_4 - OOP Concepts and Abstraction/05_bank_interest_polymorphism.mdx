# Dynamic Method Dispatch (Bank Interest)

## Problem Description
Demonstrate Dynamic Method Dispatch by declaring an array of superclass references (`CentralBank[]`) holding instantiated subclass objects (`SBIBank`, `HDFCBank`, `ICICIBank`). Resolve interest rates dynamically at runtime.

## Requirements
- Source file name: `05_bank_interest_polymorphism.java`
- Class name: `_05_bank_interest_polymorphism`
- Utilize enhanced `for-each` loop with superclass reference polymorphic invocation.

## Sample Output
```text
--- Dynamic Method Dispatch (Bank Interest Rates) ---
SBIBank Fixed Deposit Rate: 7.2%
HDFCBank Fixed Deposit Rate: 8.1%
ICICIBank Fixed Deposit Rate: 7.9%
```
