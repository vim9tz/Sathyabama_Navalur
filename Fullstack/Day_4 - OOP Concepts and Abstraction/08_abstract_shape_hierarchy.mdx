# Abstract Shape Hierarchy

## Problem Description
Create an abstract class `AbstractShape` containing an instance variable (`color`), abstract methods `calculateArea()` and `calculatePerimeter()`, and a concrete helper method `displayShapeInfo()`. Subclasses `ConcreteCircle` and `ConcreteRectangle` must provide concrete implementations for abstract methods.

## Requirements
- Source file name: `08_abstract_shape_hierarchy.java`
- Class name: `_08_abstract_shape_hierarchy`
- Abstract classes cannot be directly instantiated using `new AbstractShape(...)`.

## Sample Output
```text
--- Abstract Shape Hierarchy ---
Shape Color: Red | Area: 78.53981633974483 | Perimeter: 31.41592653589793
Shape Color: Blue | Area: 32.0 | Perimeter: 24.0
```
