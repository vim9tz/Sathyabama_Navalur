# Payment Gateway Interface Contract

## Problem Description
Define a Java interface contract `PaymentGatewayContract` with constant fields (`CURRENCY = "INR"`) and abstract operations (`initiatePayment`, `verifyStatus`). Create implementing classes `UpiPaymentGateway` and `CardPaymentGateway`.

## Requirements
- Source file name: `10_payment_gateway_interface.java`
- Class name: `_10_payment_gateway_interface`
- Utilize the `implements` keyword to realize interface contracts.
