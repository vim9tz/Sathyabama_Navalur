# Area Calculator (Method Overloading)

## Problem Description
Write a Java program that implements method overloading for area computation. Define an `area()` method overloaded by parameter types and parameter counts to calculate areas for a Square, Rectangle, and Circle.

## Requirements
- Source file name: `01_area_calculator_overloading.java`
- Class name: `_01_area_calculator_overloading`
- Formulate overloaded `area(int side)`, `area(int length, int breadth)`, and `area(double radius)` signatures.

## Sample Output
```text
--- Area Calculations (Method Overloading) ---
Area of Square (side 6): 36.0
Area of Rectangle (10 x 5): 50.0
Area of Circle (radius 4.5): 63.62
```
