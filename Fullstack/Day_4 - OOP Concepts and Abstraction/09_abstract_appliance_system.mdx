# Abstract Home Appliance System

## Problem Description
Design an abstract superclass `HomeAppliance` featuring constructors, concrete specification methods, and abstract operational lifecycle controls (`turnOn()`, `turnOff()`). Implement concrete subclasses `WashingMachine` and `Refrigerator`.

## Requirements
- Source file name: `09_abstract_appliance_system.java`
- Class name: `_09_abstract_appliance_system`
- Verify abstract class constructor invocation via `super(...)` inside child constructors.
