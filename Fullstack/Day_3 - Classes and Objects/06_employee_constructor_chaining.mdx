# Employee Constructor Chaining

## Problem Description
Design an `EmployeeMember` class implementing constructor chaining via `this(...)` calls. Ensure that constructors with fewer parameters delegate work to constructors with more parameters, ending at a master constructor.

## Requirements
- Source file name: `06_employee_constructor_chaining.java`
- Class name: `_06_employee_constructor_chaining`
- Rule: `this(...)` must be the very first line inside constructor bodies.
