# Interactive Modular Calculator

## Problem Description
Design a modular calculator where each functional task (displaying title/menu, performing addition, subtraction, multiplication, division) is separated into its own single-responsibility static method.

## Requirements
- Source file name: `02_interactive_modular_calculator.java`
- Class name: `_02_interactive_modular_calculator`
- Implement methods: `showTitle()`, `showMenu()`, `addition()`, `subtraction()`, `multiplication()`, `division()`.

## Sample Input
```text
1
20
5
5
```
