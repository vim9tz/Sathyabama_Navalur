# Inventory Management System Capstone

## Problem Description
Design a warehouse inventory tracking system using OOP core tenets. Implement `InventoryItem` and child class `PerishableItem` with methods for calculating inventory valuations and monitoring product expiration thresholds.

## Requirements
- Source file name: `12_inventory_management_system.java`
- Class name: `_12_inventory_management_system`
- Integrate methods, objects, constructors, and inheritance.
