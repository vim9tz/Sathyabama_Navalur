# Hierarchical Inheritance

## Problem Description
Design a hierarchical inheritance model where a parent class `BankAccountSuper` is inherited by two separate child classes: `SavingsAccountChild` (which adds interest calculations) and `CheckingAccountChild` (which adds overdraft line of credit capabilities).

## Requirements
- Source file name: `11_hierarchical_inheritance.java`
- Class name: `_11_hierarchical_inheritance`
- Show multiple subclasses extending the same superclass.

```text
Acc No: SAV1001 | Current Balance: ₹10000.0
Interest Added: ₹500.0 | Updated Balance: ₹10500.0

--- Checking Account ---

Withdrew ₹2500.0 | Remaining Balance: ₹-500.0
```
