# Multilevel Inheritance System

## Problem Description
Design a 3-level class hierarchy (`BasePerson` $\rightarrow$ `Staff` $\rightarrow$ `ManagerStaff`). Verify that the leaf child class `ManagerStaff` inherits all attributes and behaviors from both intermediate (`Staff`) and top-level (`BasePerson`) superclasses.

## Requirements
- Source file name: `08_multilevel_inheritance_system.java`
- Class name: `_08_multilevel_inheritance_system`
- Demonstrate attribute inheritance across three levels of class hierarchy.

Base Salary: ₹85000.0 | Allowance: ₹15000.0 | Total: ₹100000.0
