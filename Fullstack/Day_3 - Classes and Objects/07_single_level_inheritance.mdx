# Single-Level Inheritance

## Problem Description
Create a base class `BaseVehicle` with attributes `brand`, `maxSpeed`, and method `startEngine()`. Derive a subclass `CarSubclass` using `extends` to inherit attributes and add child-specific properties (`numberOfDoors`).

## Requirements
- Source file name: `07_single_level_inheritance.java`
- Class name: `_07_single_level_inheritance`
- Demonstrate inheritance using `extends`.

## Sample Output
```text
Vehicle engine started.
Brand: Tata Motors | Top Speed: 180 km/h | Doors: 4
```
