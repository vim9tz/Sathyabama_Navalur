# Super Keyword & Parent Constructors

## Problem Description
Create a parent class `EcommerceProduct` with a parameterized constructor. Derive `PhysicalProduct` and `DigitalProduct` subclasses, passing parent field values up the inheritance tree using `super(productId, name, price)`.

## Requirements
- Source file name: `09_super_keyword_constructor.java`
- Class name: `_09_super_keyword_constructor`
- Rule: `super(...)` must be the first call inside child constructors.

## Sample Output
```text
--- E-Commerce Catalog ---
ID: 201 | Name: Wireless Headphones | Price: ₹2499.0
Type: Physical Goods | Weight: 0.45 kg

ID: 301 | Name: Java Mastery E-Book | Price: ₹499.0
Type: Digital Download | URL: https://store.com/downloads/java.pdf
```
