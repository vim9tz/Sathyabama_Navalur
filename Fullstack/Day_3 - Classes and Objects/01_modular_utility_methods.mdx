# Modular Utility Methods

## Problem Description
Write a Java program demonstrating static utility methods. Implement functions `isEven(int n)`, `findMax(int a, int b, int c)`, and `getGreeting(String name)` to break program logic into reusable components.

## Requirements
- Source file name: `01_modular_utility_methods.java`
- Class name: `_01_modular_utility_methods`
- Use static methods with descriptive return types.

## Sample Input
```text
Alice
14
10 45 23
```

## Sample Output
```text
Enter your name: Alice
Hello, Alice! Welcome to Java Fullstack Course.
Enter a number to check even/odd: 14
14 is Even? true
Enter three integers (space-separated): 10 45 23
Maximum among three numbers is: 45
```
