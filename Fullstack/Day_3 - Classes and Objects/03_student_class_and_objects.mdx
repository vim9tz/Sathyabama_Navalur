# Class & Object Instantiation

## Problem Description
Define a blueprint class `StudentRecord` with fields `rollNo`, `name`, and `cgpa`. Implement methods `setDetails(...)` and `displayDetails()`, then instantiate multiple distinct objects in the `main` method.

## Requirements
- Source file name: `03_student_class_and_objects.java`
- Class name: `_03_student_class_and_objects`
- Demonstrate memory allocation using the `new` keyword.

## Sample Output
```text
--- Student Details ---
Roll No: 101 | Name: Aarav Sharma | CGPA: 8.9
Roll No: 102 | Name: Diya Patel | CGPA: 9.4
```
