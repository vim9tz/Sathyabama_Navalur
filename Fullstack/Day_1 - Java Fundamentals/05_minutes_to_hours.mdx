# Convert Minutes to Hours and Minutes

## Problem Description
Given a total duration in minutes, convert it into hours and remaining minutes.

## Requirements
- Source file name: `05_minutes_to_hours.java`.
- Calculate hours via integer division `totalMinutes / 60`.
- Calculate remaining minutes via modulo `totalMinutes % 60`.

## Sample Input
```text
135
```

## Sample Output
```text
Enter Total Minutes: 135
135 minutes is equal to 2 hours and 15 minutes.
```
