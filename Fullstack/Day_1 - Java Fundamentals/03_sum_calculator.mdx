# Sum Calculator

## Problem Description
Get two integers from standard input, compute their sum, and print the result.

## Requirements
- Source file name: `03_sum_calculator.java`.
- Read two integers using `Scanner.nextInt()`.
- Perform addition `sum = a + b`.
- Display formatted output string.

## Sample Input
```text
10
20
```

## Sample Output
```text
Enter the first number: 10
Enter the second number: 20
The sum of 10 and 20 is: 30
```
