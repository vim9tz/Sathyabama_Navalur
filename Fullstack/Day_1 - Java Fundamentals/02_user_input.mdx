# Interactive User Input in Java

## Problem Description
Read the user's name from standard input using `java.util.Scanner` and greet them dynamically.

## Requirements
- Source file name: `02_user_input.java`.
- Instantiate `Scanner` wrapping `System.in`.
- Use `scanner.nextLine()` to read user input string.
- Close the `Scanner` resource before method exit.

## Sample Input
```text
Arun
```

## Sample Output
```text
Enter your name: Arun
Hello, Arun!
```
