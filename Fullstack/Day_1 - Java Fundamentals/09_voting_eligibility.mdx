# Voting Eligibility Evaluator

## Problem Description
Read the age of a person. If age is 18 or above, print eligibility for voting.

## Requirements
- Source file name: `09_voting_eligibility.java`.
- Use single `if-else` condition (`age >= 18`).

## Sample Input
```text
20
```

## Sample Output
```text
Enter your age: 20
You are eligible to vote.
```
