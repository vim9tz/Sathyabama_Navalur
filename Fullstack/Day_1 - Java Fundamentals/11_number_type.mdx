# Positive, Negative, or Zero Classifier

## Problem Description
Read a number and determine whether it is positive, negative, or zero using an `if-else if-else` ladder.

## Requirements
- Source file name: `11_number_type.java`.
- Check `number > 0`, `number < 0`, and fallback to zero.

## Sample Input
```text
-15
```

## Sample Output
```text
Enter a number: -15
-15 is a negative number.
```
