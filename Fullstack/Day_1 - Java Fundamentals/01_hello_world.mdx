# Hello World in Java

## Problem Description
Write your first Java program. Create a class `_01_hello_world` containing the standard `main` method, and output "Hello, World!" to the console.

## Requirements
- Source file name: `01_hello_world.java`.
- Use `System.out.println` for line printing.
- Clean execution with zero warnings.

## Sample Input
No input required.

## Sample Output
```text
Hello, World!
```
