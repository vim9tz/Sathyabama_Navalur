# Placement Eligibility Using Nested IF

## Problem Description
Evaluate placement eligibility using two sequential conditions:
1. CGPA >= 7.0
2. Arrears == 0

## Requirements
- Source file name: `12_placement_eligibility.java`.
- First validate CGPA. Only if CGPA >= 7.0, read arrears and validate.

## Sample Input
```text
8.2
0
```

## Sample Output
```text
Enter your CGPA: 8.2
Enter number of arrears: 0
You are eligible for placement.
```
