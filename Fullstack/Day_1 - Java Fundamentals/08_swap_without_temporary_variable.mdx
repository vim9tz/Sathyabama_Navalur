# Swap Two Numbers Without Temporary Variable

## Problem Description
Swap two integer variables `a` and `b` without allocating additional temporary memory.

## Requirements
- Source file name: `08_swap_without_temporary_variable.java`.
- Use arithmetic operations: `a = a + b`, `b = a - b`, `a = a - b`.

## Sample Input
```text
10
20
```

## Sample Output
```text
Enter a: 10
Enter b: 20
Before swapping: a = 10, b = 20
After swapping: a = 20, b = 10
```
