# Swap Two Numbers Using Temporary Variable

## Problem Description
Read two integer variables `a` and `b`, swap their contents using a third temporary variable `temp`, and print values before and after swapping.

## Requirements
- Source file name: `07_swap_using_temporary_variable.java`.
- Store initial value `temp = a`.
- Assign `a = b` and `b = temp`.

## Sample Input
```text
10
20
```

## Sample Output
```text
Enter a: 10
Enter b: 20
Before swapping: a = 10, b = 20
After swapping: a = 20, b = 10
```
